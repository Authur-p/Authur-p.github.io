GAN-based cloud removal with a Copernicus data-enrichment pipeline

I built an automated SAR-optical data pipeline — Copernicus API, patch-level cloud segmentation and matched-pair assembly — that grew the 15-channel training set from 28,617 to 58,458 triplets across ten Sentinel-2 tiles under automated quality control. I diagnosed a silent post-2022 Sentinel-2 radiometric offset and corrected it, then traced reconstruction artefacts to transposed-convolution up-sampling, batch-norm test-time statistics and normalisation — running 15+ controlled experiments on the ARCHIE-WeSt HPC cluster (SLURM).
